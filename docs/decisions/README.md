# Architecture Decision Records

ADR ghi quyết định khó đảo ngược hoặc ảnh hưởng scope, data split, taxonomy, metric và service boundary.

Tên file:

```text
ADR-NNNN-short-title.md
```

Mỗi ADR gồm:

- Status và ngày.
- Context.
- Decision.
- Consequences.
- Alternatives considered.
- Evidence cần kiểm lại.
