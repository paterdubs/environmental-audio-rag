# Measurements

Thư mục chứa báo cáo sinh tự động hoặc kết luận thực nghiệm có liên kết tới artifact.

Quy ước:

- Filename gồm chủ đề và ngày `YYYYMMDD`.
- Header ghi run ID, command, config hash, split hash, taxonomy hash.
- Bảng số sinh từ machine-readable results; không chép tay.
- Kết luận phải tách observation, interpretation và limitation.
- Không commit checkpoint hoặc prediction tensor vào đây.
