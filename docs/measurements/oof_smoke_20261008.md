- Synthetic target-contaminated logits; not model performance or scientific evidence.
- Completed pipeline uses 1Hz frames, true recording duration and 10s windows/hop; not the native 100Hz T2b grid. Coarse timing can change event F1 and collapses tau half-window to 1 frame across the cSEBB grid. Do not use to select a model or budget native OOF.

- Worker counts differ: theta3, baseline cSEBB2, candidate cSEBB8 (CPU wrapper logs override). Do not compare wall times across systems as a model speed benchmark.
- RAM sampled every 0.5s per subprocess tree; misses between-sample peaks, includes shared pages and excludes orchestration process. Not GPU VRAM.
- 100Hz/10Hz partial attempts stopped deliberately, not passed end-to-end.
